🎬 Netflix Data Analysis & Viewer Insights Dashboard
📌 Project Overview
This project provides a comprehensive end-to-end data analysis of Netflix content performance and viewer behavior using Power BI and Excel[cite: 1]. The analysis evaluates customer demographics, watch time distribution across subscription tiers, regional content engagement, and content ratings to deliver data-driven recommendations for streaming strategy[cite: 1, 2, 3].

📊 Key Highlights & Metrics
Total Watch Time: 835.21K Hours (~50.1M Minutes) across global audiences[cite: 7].

Total Customers Analyzed: 20,000 registered users[cite: 7].

Global Market Reach: Covered 10 major streaming regions across North America, Europe, Asia-Pacific, and South America[cite: 7].

Subscription Tiers Evaluated: Basic, Standard, and Premium subscription plans[cite: 2, 7].

🎯 Key Business Questions Addressed
Subscriber Engagement: Which age demographics and subscription tiers drive the majority of watch hours[cite: 2]?

Regional Performance: How does viewer engagement vary across top market countries like France, India, Canada, and the USA[cite: 2, 7]?

Content Analytics: What are the top-performing titles based on total watch minutes[cite: 2, 7]?

Subscription Tier Dynamics: How balanced is engagement across Basic, Standard, and Premium plans[cite: 2, 7]?

🛠️ Tech Stack & Tools Used
Power BI Desktop: Data modeling, DAX measures, interactive visuals, theme customization, and slicers[cite: 1, 3, 7].

Power Query: Data cleaning, handling missing values, type transformations, and schema mapping[cite: 1].

Microsoft Excel: Data exploration and initial dataset verification[cite: 1].

DAX (Data Analysis Expressions): Custom measures for aggregation, conditional columns, and age bracket grouping[cite: 1, 2].
